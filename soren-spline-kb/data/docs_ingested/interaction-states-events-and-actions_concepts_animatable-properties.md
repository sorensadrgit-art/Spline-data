# Animatable Properties (/interaction-states-events-and-actions/concepts/animatable-properties)



Here's a list of properties that can be animated using states and events in Spline.

### All Objects [#all-objects]

* Position, Rotation, Scale
* Size (X, Y, Z)
* Extrusion
* Material Layers

### Particle Emitter & Force [#particle-emitter--force]

* Position, Rotation

### Cameras [#cameras]

* Position, Rotation, Scale
* Zoom

### Light Objects [#light-objects]

* Position, Rotation, Scale
* Color, Intensity

### 3D Paths [#3d-paths]

* Position, Rotation, Scale
* Depth, Offset
* Angel, Twist
* Start Scale, End Scale

### Align to Path [#align-to-path]

* Offset
* Slide

### Cloner Properties [#cloner-properties]

| Radial Type | Linear Type | Grid Type |   | Randomness |
| ----------- | ----------- | --------- | - | ---------- |
| Count       | Count       | Count     |   | Strength   |
| Position    | Position    | Size      |   | Position   |
| Scale       | Scale       |           |   | Scale      |
| Rotation    | Rotation    |           |   | Rotation   |
| Radius      |             |           |   | Seed       |
| Start       |             |           |   | Movement   |
| End         |             |           |   | Scale      |
