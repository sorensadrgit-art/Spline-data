# Exporting Image Sequences (/exporting-your-scene/files/exporting-image-sequences)

> Render your scene as a numbered sequence of images for use in video and motion tools.



<Image src="https://cdn.spline.design/_assets/docs/36a3b967-8d3b-4a63-93f5-77370663edae.png" alt="image" />

1. Once you're happy with your scene, press the Export button on the toolbar.
2. Scroll down to select "Video Recording" export under *Files* category from the export sidebar.
3. Select “Image Sequence” from the *Format* dropdown
4. Choose the type of image file you want to save (JPG or PNG).
5. Set desired Frame rate in the *FPS* dropdown (15, 24, 30, 48, 60).
6. In the *Time* dropdown, you can choose to either use a fixed duration or a manual duration for your Image Sequence.
   1. If you select a fixed duration, press "Start" to start recording and the Image Sequence will be automatically stopped at the set duration.
   2. If you select a manual duration, you'll need to manually control the beginning and the end of your Image Sequence with the "Start" and "Stop" buttons.
7. After your Image Sequence is recorded you'll be prompted to save ZIP of images captured.
