# Displace Layer (/materials-shading/surface-detail/displace-layer)



The Displace Layer distorts the object's geometry (usually known as displacement).

This layer uses Noise Displacement (similar to how the Noise layer works, but it only distorts the geometry).

You can choose between different types of noise on the "Type" option.
