# Exporting as USDZ (/exporting-your-scene/files/exporting-as-usdz)



USDZ is an open-source file format for 3D models, initially started by Pixar in collaboration with Apple. It is supported by default in Apple platforms.

<Callout>
  Exporting USDZ format is a paid feature, you’ll need to have an active **Pro** or **Max** subscription to use it.
</Callout>

<Image src="https://cdn.spline.design/_assets/docs/4da41d73-381f-4d1b-942c-ecc66935dc87.png" alt="image" />

1. Once you're happy with your scene, press the Export button on the toolbar.
2. Scroll down to select "3D Formats" under *Files* section from the export sidebar.
3. Choose “USDZ” from the *Format* dropdown and click Export.

<Callout>
  Some material layers are not fully supported by the USDZ format. Texture support is limited to only primitive geometries with UV projection mode. No texture support for geometries with “Smooth & Edit”.
</Callout>

#### ✅ Supported features [#supported-features]

* Geometry
* Color Layer
* Textures (Only Basic Support)

#### ❌ Not supported features [#not-supported-features]

* All Material Layers
* Post-Processing
* Animation
* Physics
* Environment, Lighting, and Fog
* States, Events, and Interactivity
* Assets, Components, and Variables

### AR with Apple (iOS) with Spline [#ar-with-apple-ios-with-spline]

Open the USDZ file on your iPhone or iPad to see it in Augmented Reality.
