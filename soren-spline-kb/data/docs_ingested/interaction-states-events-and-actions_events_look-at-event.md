# Look At Event (/interaction-states-events-and-actions/events/look-at-event)



The Look At Event is used to create interactions where objects will face toward either the cursor or another object.

<Video src="https://cdn.spline.design/_assets/docs/d8c5093e-2549-49b2-a83f-fd3c1a9e8a3f.mp4" />

Here are the different properties of a Look At Event:

* **Target** - Where is the object looking at.
* **Plane** - To what plane should the object movement be restricted to.
* **Distance** - Intensity of the object rotation based on the distance to target.
* **Direction** - What axis should the object look towards.
* **Damping** - Makes the look at effect lag behind whatever it is tracking.
* **Reset If** - If the object should reset back to its original position or not when the mouse is out of the canvas.
