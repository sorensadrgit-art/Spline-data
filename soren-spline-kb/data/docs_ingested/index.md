# Getting Started (/)

> Learn how to design, animate and publish interactive 3D and 2D experiences with Spline.



Spline is a design tool for making interactive 3D and 2D experiences in your
browser, and shipping them to the web, iOS and Android.

It's two editors in one product. The **3D editor** is for modelling, materials,
lighting, animation and physics. **Hana** is a 2D canvas for interfaces and
animated graphics. Both share the same interactivity model, the same real-time
collaboration and the same publishing pipeline — and both have an AI agent that
can build and edit for you.
