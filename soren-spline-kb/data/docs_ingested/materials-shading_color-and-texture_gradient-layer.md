# Gradient Layer (/materials-shading/color-and-texture/gradient-layer)



Gradient color shows a transition between 2 or more colors. Following parameters can be adjusted:

* **Type** (Linear, Radial, Polar)
* **Blending** (Linear, Smooth)
* **Ramp** (Adjust transition location between colors. Hint: click to add color to the ramp, select it and hit delete to remove it.)
* **Color** (Adjust for each color on ramp.)
* **Angle** (Define the angle of the gradient.)
* **Offset** (Offset the gradient on the X and Y axis.)
* **Morph** (Create cool morphing effects on the X and Y axis.)
