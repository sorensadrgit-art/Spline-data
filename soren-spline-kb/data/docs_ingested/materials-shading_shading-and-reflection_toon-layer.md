# Toon Layer (/materials-shading/shading-and-reflection/toon-layer)



The toon layer can be used in combination with the [Outline Layer](https://docs.spline.design/materials-shading/surface-detail/outline-layer.md) to create hand-drawn style effects.

<Embed src="https://www.youtube.com/embed/5tq9R2zQxYg" title="YouTube video player" />

The following parameters can be adjusted:

* **Position** - The position where the gradient is pointing, the default is set to camera but it can be changed to follow the lights or to be static.
* **Gradient** - Affects the shading of the object.
* **Offset** - Changes the gradient location from the object origin.
* **Noise** - Strength of the noise effect.
* **Noise Scale** - Controls the noise frequency scale.
