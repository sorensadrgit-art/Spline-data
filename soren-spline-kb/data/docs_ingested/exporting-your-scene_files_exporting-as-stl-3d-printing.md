# Exporting as STL (3D Printing) (/exporting-your-scene/files/exporting-as-stl-3d-printing)



STL is a 3D format commonly used for 3D printing or CAD.

<Callout>
  Exporting STL format is a paid feature, you’ll need to have an active **Pro** or **Max** subscription to use it.
</Callout>

<Image src="https://cdn.spline.design/_assets/docs/a5ba0376-3f68-4784-8178-18c70b8d2f43.png" alt="image" />

1. Once you're happy with your scene, press the Export button on the toolbar.
2. Scroll down to select "3D Printing" under *Files* section from the export sidebar.
3. Press Export to save the scene as STL file.

You can later import the resulting STL file into a 3D printing app to 3D print your model.

<Callout>
  STL is a geometry-only format. It does not contain color or material information. The STL file format can be used for 3D Printing or in CAD software.
</Callout>

#### ✅ Supported features [#supported-features]

* Geometry

#### ❌ Not supported features [#not-supported-features]

* Color Layer
* Textures (Only Basic Support)
* All Material Layers
* Post-Processing
* Animation
* Physics
* Environment, Lighting, and Fog
* States, Events, and Interactivity
* Assets, Components, and Variables
