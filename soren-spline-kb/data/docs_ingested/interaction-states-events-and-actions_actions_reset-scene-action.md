# Reset Scene Action (/interaction-states-events-and-actions/actions/reset-scene-action)



The Reset Scene action is used when there’s a need to fully reset the whole scene based on input by the user.

<Video src="https://cdn.spline.design/_assets/docs/57d0713e-9632-4704-931a-c90052dadc3a.mp4" />

## Creating a new Reset Scene Action [#creating-a-new-reset-scene-action]

1. Select the object to which you want to add a reset scene action to.
2. On the Events panel, add one of the following events: Mouse Down / Up / Press or Key Down / Up / Press.
3. Open the Event and add a Reset Scene action.
