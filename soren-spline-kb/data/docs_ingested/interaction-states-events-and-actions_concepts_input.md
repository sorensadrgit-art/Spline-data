# Input (/interaction-states-events-and-actions/concepts/input)



An Input object lets you create a dynamic input field. It’s a great way to connect with API, Webhooks or OpenAI API to send user-created text or prompts.

[OpenAI API](https://docs.spline.design/interaction-states-events-and-actions/variables-and-data/ai-text-open-ai-api.md)

[Real-time API](https://docs.spline.design/interaction-states-events-and-actions/variables-and-data/real-time-api.md)

[Webhooks](https://docs.spline.design/interaction-states-events-and-actions/variables-and-data/webhooks.md)

To create an Input follow these steps:

1. Click on the `+` icon in the editor’s toolbar
2. Select the `Input object` in the list.
3. Drag an area in the viewport to define the input field’s area
4. Define the text properties, to learn more about working with text read the following doc: [Working with Text](https://docs.spline.design/designing-in-3-d/objects/working-with-text.md)
