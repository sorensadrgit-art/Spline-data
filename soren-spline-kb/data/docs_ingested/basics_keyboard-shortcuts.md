# Keyboard shortcuts (/basics/keyboard-shortcuts)

> Every keyboard shortcut in the Spline 3D editor, grouped by what it does.



### Key symbols (mac) [#key-symbols-mac]

⌘ - CMD \
⇧ - Shift \
⌃ - Control \
⌥ - Option / Alt
