# Integrating with Wix (/integrations/integrating-with-wix)



<Image src="https://cdn.spline.design/_assets/docs/44f40ae7-2fac-48be-a80d-1efbbcf1f253.png" alt="image" />

Integrating your Spline scenes into Wix allows you to have real-time interactive 3D experiences on your Wix websites.

[Learn more about Wix →](https://www.wix.com/)

## Add a 3D embed to your Wix website [#add-a-3d-embed-to-your-wix-website]

1. Press **Add Elements** in the toolbar on the left (+ icon).
2. Choose &#x2A;*Embed Code,** then **Popular Embeds**.
3. Press the + icon next to &#x2A;*Embed HTML.**
4. Paste your Spline Viewer code snippet into the code input under **Add your code here** and press &#x2A;*Update.**

[Learn more on Wix docs →](https://support.wix.com/en/article/wix-editor-embedding-a-site-or-a-widget#adding-an-embed)
