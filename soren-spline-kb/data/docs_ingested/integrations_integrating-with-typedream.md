# Integrating with Typedream (/integrations/integrating-with-typedream)



<Image src="https://cdn.spline.design/_assets/docs/06c058df-97a4-445b-9817-8c95fb8bbb2e.png" alt="image" />

Typedream is a no-code website builder that allows users to create and manage websites without coding. It offers features like video backgrounds, image carousels, and integration with data sources such as Notion, Airtable, and Google Sheets.

[Learn more about Typedream →](https://typedream.com/)

Integrating your Spline scenes into Typedream allows you to have real-time interactive 3D experiences on your Typedream websites.

## Add a 3D embed to your Typedream website [#add-a-3d-embed-to-your-typedream-website]

1. Create an embed block by typing &#x2A;*/Embed.**
2. Press the Embed block and go to the Code tab.
3. Paste your Spline Viewer code snippet in the text field.
4. Press &#x2A;*Insert Code.**

[Learn more on Typedream docs →](https://typedream.com/docs/integration/spline)
