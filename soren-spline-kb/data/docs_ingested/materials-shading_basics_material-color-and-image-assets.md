# Material, Color, and Image Assets (/materials-shading/basics/material-color-and-image-assets)

> Save materials, colours and images as reusable assets you can apply across a scene.



**You can create assets for the following types:**

* Material (combination of material layers)
* Color
* Image
* Media (Videos)
* Audio

Created assets can be quickly applied to multiple objects. If the asset is adjusted, all objects using it get updated with the changes.

<Video src="https://cdn.spline.design/_assets/docs/bb493e48-4ba1-4720-bf37-ca710b11e27d.mp4" />

When no object is selected, you can find a list of all the assets (Material, Color, Image) created on each scene on the right sidebar.

Clicking on the assets is also a quick way to edit any asset without having to select an object.

## Cleaning up unused assets [#cleaning-up-unused-assets]

It might come in handy to do a clean-up on the unused material assets in your scene to get more organized.

To do so, follow these steps:

1. Unselect everything in your scene.
2. Scroll down on the inspector sidebar until you find the Material Assets Panel.
3. On this panel, click the ‘more’ icon and select ‘Remove Unused Assets’.

This will clean up any assets that are not applied to an object.

Make sure you don’t want to keep any of them but you can undo this action to double-check.
