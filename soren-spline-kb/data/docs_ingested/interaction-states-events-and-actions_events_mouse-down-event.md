# Mouse Down Event (/interaction-states-events-and-actions/events/mouse-down-event)



The Mouse Events require the user to perform an action with the mouse (or touch) to trigger all the actions inside.

A Mouse Down Event will trigger the actions as soon as the mouse button is pressed.

<Video src="https://cdn.spline.design/_assets/docs/6fa0aaa8-9b05-4cb5-b865-c242ef8afbc8.mp4" />

#### Trigger Property [#trigger-property]

You can choose how to trigger the event, either on the object the event is added or anywhere in the scene.

Here are the different Actions you can trigger with the Mouse Down Event:

* [Animation Action](https://docs.spline.design/interaction-states-events-and-actions/actions/animation-action.md)

* [Video Action](https://docs.spline.design/interaction-states-events-and-actions/actions/video-action.md)
* [Open Link Action](https://docs.spline.design/interaction-states-events-and-actions/actions/open-link-action.md)
