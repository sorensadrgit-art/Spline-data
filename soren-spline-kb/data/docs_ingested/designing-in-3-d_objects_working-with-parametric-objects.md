# Working with Parametric Objects (/designing-in-3-d/objects/working-with-parametric-objects)



<Callout>
  A parametric object is an object that always retains its original parameters after being modified.
</Callout>

On Spline, the parametric objects can be accessed by pressing the `+` icon on the toolbar.
