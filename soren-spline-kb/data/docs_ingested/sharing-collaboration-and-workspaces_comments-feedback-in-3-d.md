# Comments & Feedback in 3D (/sharing-collaboration-and-workspaces/comments-feedback-in-3-d)



Comments allow a more intuitive collaboration workflow with your team and friends right inside Spline. Leave feedback, save notes, or share ideas by simply leaving a comment on your 3D scenes.

## Creating a Comment [#creating-a-comment]

To create a new comment thread:

1. Select the comment tool from the toolbar or use the shortcut **C**
2. On the viewport, press on the position where you want to create a new comment
3. Input your message and press **Enter** or the send button

<Callout>
  Comments will stick to objects in the 3D space.
</Callout>

## Creating a Reply [#creating-a-reply]

To reply to an existing comment thread:

1. Open the comment thread by pressing the comment pin on the viewport
2. Type your reply on the input at the bottom and press **Enter** or the send button

<Video src="https://cdn.spline.design/_assets/docs/f4a12e67-7a4a-40a9-83a8-4e1f6c189a41.mp4" />

## Editing a Comment or Reply [#editing-a-comment-or-reply]

After identifying the comment or reply you want to edit:

1. Open the comment thread by pressing the comment pin on the viewport
2. Press the options icon to the right of the commenter's name and select ‘Edit’
3. Make changes to the original comment/reply and press **Enter** or the save button

<Callout>
  Both Editors and Viewers can only edit comments or replies made by themselves.
</Callout>

<Video src="https://cdn.spline.design/_assets/docs/dca71488-de34-4eca-89d7-1be5a5bad44d.mp4" />

## Deleting a Comment or Reply [#deleting-a-comment-or-reply]

After identifying the comment or reply you want to delete:

1. Open the comment thread by pressing the comment pin on the viewport
2. Press the options icon to the right of the commenter's name and choose Edit
3. On the confirmation modal, press Delete.

<Callout>
  Editors can delete/resolve comments or replies from everyone while viewers can only delete their own comments and replies.
</Callout>
