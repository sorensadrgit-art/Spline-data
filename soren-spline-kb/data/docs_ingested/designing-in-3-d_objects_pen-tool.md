# Pen Tool (/designing-in-3-d/objects/pen-tool)



<Callout>
  A vector shape can be edited by double-pressing it. Exit the vector editing mode by double-pressing anywhere on the viewport or by pressing the `ESC` key.
</Callout>

The pen tool enables you to create custom 2D shapes in the 3D space. It works in a familiar way to other 2D or UI design tools.

Start by selecting the pen tool on the toolbar and creating the points of your vector shape - you can create straight points by clicking shift while drawing.

<Video src="https://cdn.spline.design/_assets/docs/457542ad-6291-4267-9941-dc0ffd871ce2.mp4" />

## Curve [#curve]

To add a curve to your points you can either `Press + Drag` while adding a point or use the bend tool (by selecting it on the toolbar or by clicking `⌘` / `Ctrl` for a shortcut).

You can break a curve by pressing `⌥&#x60; &#x2A;*/** `Alt` while you are **dragging** the curve handle.

<Video src="https://cdn.spline.design/_assets/docs/af2250ba-94ae-449c-a1be-4fb5beca0347.mp4" />

## Extrusion [#extrusion]

The fun part comes when we add extrusion and get to work with a 3D vector shape.

To do it, simply go to the shape panel and add extrusion to your shape. Don't forget to add lighting to your shape on the material panel.

<Video src="https://cdn.spline.design/_assets/docs/755a6b7e-bc68-4346-9ab6-2cce8b576eca.mp4" />

## Rounded Corners [#rounded-corners]

You can also add rounded corners to the vector shapes.

<Video src="https://cdn.spline.design/_assets/docs/ff95ce7c-f024-468b-bc8d-d763144fb078.mp4" />

## Bevels (Corners) [#bevels-corners]

If you add extrusion to your shape, you can add rounded edges to the resulting volume (it’s usually called bevels).
