# Team Libraries (/sharing-collaboration-and-workspaces/team-libraries)



A Team Library is your central hub for design assets. Create a library with components, materials, colors, images, and audio assets for your team to use. Easily cross-reference and update them across files, without the hassle of individual updates.

Simplify collaboration and establish an efficient design system with Team Libraries. Discover how to integrate it into your workflow with the following steps.

## Create a Team Library [#create-a-team-library]

1. Create a new file or open an existing one. The file should be created or stored on a team as libraries are only available for teams.
2. Create assets in the file (components, colors, images, media, audio).
3. Press the “Assets” tab on the left sidebar.
4. Press the “Manage Libraries” button.
5. Press the “Use as Team Library” button and the publishing will start.

<Video src="https://cdn.spline.design/_assets/docs/337fc9e0-5bc3-40a0-8ddf-6d41b84e9c45.mp4" />

<Callout>
  It's a good practice to create a dedicated file for your Team Library, such as your 3D design
  system, which you can reference in multiple files and make updates to.
</Callout>

## Disable a Team Library [#disable-a-team-library]

1. Press the “Assets” tab on the left sidebar.
2. Press the “Manage Libraries” button.
3. Hover the “Enabled” element next to the library name.
4. Press the “Disable Library” button.

<Image src="https://cdn.spline.design/_assets/docs/9584d4c5-f6a9-4fae-ae00-74ccc78608b0.png" alt="image" maxWidth="300" />

<Callout>
  The assets on this file will not be visible in other team files and the connection will be broken
  with assets already used in other files. Enabling the library again will reconnect the assets used
  in other files.
</Callout>

## Enable Team Libraries on other files [#enable-team-libraries-on-other-files]

1. Open the file where you would like to use and reference a Team Library.
2. Press the “Assets” tab on the left sidebar.
3. Press the “Manage Libraries” button.
4. At the “Team Libraries” section, turn on the libraries you would like to have access to on your file.

<Video src="https://cdn.spline.design/_assets/docs/f2da90de-40a4-4296-83f5-cfcb4a339088.mp4" />

## Use Team Libraries’ assets on other files [#use-team-libraries-assets-on-other-files]

1. After enabling a Team Library, on the “Assets” tab, you can select the specific library from the dropdown menu and start using components or assets from that library.
2. Drag and drop components or materials from the asset browser.
3. When an object is selected, get access to the enabled libraries directly in the assets browsers and swap them (component, material, color, image, audio, or media).

<Video src="https://cdn.spline.design/_assets/docs/ee1db6e7-8e3c-45ee-9820-226e1d75aa70.mp4" />

## Push new changes on a Library [#push-new-changes-on-a-library]

1. Open the Team Library file.
2. Make any changes to your assets (components, material, color, image, media, or audio).
3. Press the “Assets” tab on the left sidebar.
4. Press the "Push New Changes" button that will show up on the sidebar or inside the Library Manager.

<Video src="https://cdn.spline.design/_assets/docs/33f63111-537d-40d3-a518-09af589f0b14.mp4" />

## Get new changes from Libraries [#get-new-changes-from-libraries]

1. Open the file where you would like to get the changes from the team library.
2. A purple dot will show up on the assets tab, letting you know there are new updates from your libraries.
3. Press the “Assets” tab on the left sidebar.
4. Press the “Get New Changes” button to get the new updates.
