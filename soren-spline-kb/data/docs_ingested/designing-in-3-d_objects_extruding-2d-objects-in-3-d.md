# Extruding 2D objects in 3D (/designing-in-3-d/objects/extruding-2d-objects-in-3-d)



Although 2D objects don't have a depth parameter, they can quickly become 3D using a modeling operation called **Extrusion**.

## How to extrude a 2D object [#how-to-extrude-a-2d-object]

1. Select the object you want to extrude.
2. Go to the **Shape** panel on the right sidebar and add value to the **Extrusion** property by typing or sliding to the desired amount.

## Tips when working with extrusions [#tips-when-working-with-extrusions]

* Change the lighting type to &#x2A;*Lambert Phong Physical,** or **Toon** if you want it to to achieve different styles.
* The position of the lightning layer matters, Hide or unhide the layer to receive light/shadows.
* Ensure that you select **Front** on the Visibility Panel; this will improve surface shading on the object when enabling shadows.
