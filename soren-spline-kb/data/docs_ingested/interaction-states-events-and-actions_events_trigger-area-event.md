# Trigger Area Event (/interaction-states-events-and-actions/events/trigger-area-event)



A Trigger Area Event will trigger the actions as soon as any object or a specific object gets inside a defined area.

<Video src="https://cdn.spline.design/_assets/docs/76cc847a-2243-4ea5-8750-53eecaf4656c.mp4" />

***

### Settings for Trigger Event [#settings-for-trigger-event]

**Toggle Property**

* The Toggle option means that when the event is first triggered, the actions go one way and when it's triggered again the actions come back, creating a toggle effect.

**Objects**

* All → every object will be considered for the Trigger Area detection.
* Custom → choose a specific object to be considered for the Trigger Area detection.

**Zone**

* The type of area. It can be a box or a sphere.

**Transform** (Size, Position & Rotation)

* Define the transform values for the trigger area.

**Helper**

* Show or hide the visualization of the trigger area in the editor.

**Actions**

Here are the different Actions you can trigger with the Trigger Area Event:

* [Transition Action](https://docs.spline.design/interaction-states-events-and-actions/actions/transition-action.md)
* [Sound Action](https://docs.spline.design/interaction-states-events-and-actions/actions/sound-action.md)
* [Open Link Action](https://docs.spline.design/interaction-states-events-and-actions/actions/open-link-action.md)
* [Create Object Action](https://docs.spline.design/interaction-states-events-and-actions/actions/create-object-action.md)
* [Destroy Object Action](https://docs.spline.design/interaction-states-events-and-actions/actions/destroy-object-action.md)
* [Switch Camera Action](https://docs.spline.design/interaction-states-events-and-actions/actions/switch-camera-action.md)
* [Scene Transition Action](https://docs.spline.design/interaction-states-events-and-actions/actions/scene-transition-action.md)
* [Reset Scene Action](https://docs.spline.design/interaction-states-events-and-actions/actions/reset-scene-action.md)
