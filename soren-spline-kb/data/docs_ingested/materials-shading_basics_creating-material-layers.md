# Creating Material Layers (/materials-shading/basics/creating-material-layers)

> How material layers stack, and how to add, reorder and combine them to build a surface.



<Callout>
  To create a new material layer, select an object, go to the Material panel in the Right Sidebar, then press "+" to add a new layer.
</Callout>

On Spline, materials work in a layer-based approach, which means that you can control an object's look by creating or editing layers on a vertical stack. This approach is different from traditional 3d editors, but it is akin to how most graphic design tools work.

## The default material layers [#the-default-material-layers]

<Image src="https://cdn.spline.design/_assets/docs/c1724073-42bd-4a29-b43d-5169711813e9.png" alt="image" maxWidth="300" />

By default, any object on Spline includes two material layers: Color and Lighting.

For 2D objects like the Rectangle and the Circle, the Lighting layer is set to "None", which means that it doesn't have any visual effect on the object. For 3D objects, the Lighting layer is set to “Phong” by default.

## Layer Properties [#layer-properties]

All material layers are different, but they all share the Opacity and Blending parameters.
