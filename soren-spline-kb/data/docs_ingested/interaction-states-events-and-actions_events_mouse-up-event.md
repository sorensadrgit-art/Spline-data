# Mouse Up Event (/interaction-states-events-and-actions/events/mouse-up-event)



The Mouse Events require the user to perform an action with the mouse (or touch) to trigger all the actions inside.

A Mouse Up Event will trigger the actions only when the mouse button is released.

<Video src="https://cdn.spline.design/_assets/docs/7699ee99-10e3-4a3a-8ec1-946b6c2a960f.mp4" />

#### Trigger Property [#trigger-property]

You can choose how to trigger the event, either on the object the event is added or anywhere in the scene.

Here are the different Actions you can trigger with the Mouse Up Event:
