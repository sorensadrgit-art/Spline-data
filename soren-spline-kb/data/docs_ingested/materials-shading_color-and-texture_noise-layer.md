# Noise Layer (/materials-shading/color-and-texture/noise-layer)



The Noise Layer is ideal to simulate organic color changes in surfaces.

Below are the supported types for noises:

* Simplex
* Simplex Fractal
* Ashima
* Fbm
* Perlin
* Voronoi

You can change size, scale and movement of the noise. Apply multiple colors to create unique variations of noise.
