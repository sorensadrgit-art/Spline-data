# Pattern Layer (/materials-shading/color-and-texture/pattern-layer)



The Pattern layer can be used to generate and achieve different types of patterns to texture your 3D objects.

<Video src="https://cdn.spline.design/_assets/docs/486a5b4c-a257-47d2-a115-107cab57587f.mp4" />

## How to create a Pattern Layer [#how-to-create-a-pattern-layer]

To add a pattern layer, you’ll need to:

1. Select an object and add a new layer on the Material Panel.
2. Change the layer to &#x2A;*“Pattern”** by clicking on the dropdown on the newly created layer.
3. Open the **Pattern Layer** settings by clicking on the layer thumbnail.

<Video src="https://cdn.spline.design/_assets/docs/5556f448-9e00-4e20-a309-1ee258e5b709.mp4" />

## Pattern Layer Settings [#pattern-layer-settings]

### Mode [#mode]

Some layers, including Pattern Layer, have the ability to be used as masks, which you can do by selecting Mask on the layer mode. Learn more here: [Layer Masking](https://docs.spline.design/materials-shading/basics/layer-masking.md).

### Settings [#settings]

**Style** → The type of pattern (Circle, Ring, Polygon, Cross, Diamond, Checkerboard, Line, and Wave)

**Parameters for each style** → Each style has its own settings that you can adjust. We encourage you to experiment to find your desired pattern.

Some of these common parameters of the Pattern styles are:

* Projection (UV, Spherical, Triplanar
* Offset (X, Y)
* Colors
* Frequency / Size / Variation / Rotation, etc…
* Vertical (Top, Bottom) /Horizontal (Left, Right)
