# FAQ (/basics/faq)

> Answers to common questions about Spline — supported import and export formats, integrations, and where to get help.



## 📸 What types of content can I export with Spline? [#-what-types-of-content-can-i-export-with-spline]

<Callout>
  You can export the content of your scene by pressing "Export" on the Toolbar.
</Callout>

#### 🥕 3D Content [#-3d-content]

* For the **Web**
  * [Exporting as Public URLs](https://docs.spline.design/exporting-your-scene/web/exporting-as-public-ur-ls.md) - A URL hosted on Spline servers, at [my.spline.design](http://my.spline.design).
  * [Exporting as Spline Viewer](https://docs.spline.design/exporting-your-scene/web/exporting-as-spline-viewer.md) - Embed Spline 3D content with a code snippet.
  * [Exporting as Code](https://docs.spline.design/exporting-your-scene/web/exporting-as-code.md) - Export code to make more complex integrations and use Spline API.
* For **Apple Platforms**
  * [Native 3D Embeds for iOS](https://docs.spline.design/exporting-your-scene/apple-platform/native-3d-embeds-for-i-os.md) - Embed your scenes with Swift Native 3D for Apple Platforms.
  * [iOS App Generation](https://docs.spline.design/exporting-your-scene/apple-platform/i-os-app-generation.md) - Generate pre-built Xcode Projects with App Generation.
  * Export for Vision Pro and preview your 3D content with [Spline Mirror for visionOS](https://docs.spline.design/exporting-your-scene/apple-platform/spline-mirror-for-vision-os.md).
* For **Android Platforms**
  * [Native 3D Embeds for Android](https://docs.spline.design/exporting-your-scene/android/native-3d-embeds-for-android.md) - Embed your scenes with Kotlin Native 3D for Android.
  * [Android Package (APK)](https://docs.spline.design/exporting-your-scene/android/android-package-apk.md) - Export pre-built Android Packages (APK).
  * [Android App Bundles (AAB)](https://docs.spline.design/exporting-your-scene/android/android-app-bundles-aab.md) - Export pre-built Android App Bundles (AAB).
* 3D Formats
  * GLTF (.gltf)
  * GLB (.glb)
  * STL (3D Printing)
  * USDZ (iOS AR)
* Spline Files (Files with ".spline" for saving your scenes locally).

#### 🖼 Image [#-image]

* PNG
* JPG

#### 🎥 Video [#-video]

* WebM
* Mp4
* Image Sequence

## 🖼 What types of content can I import with Spline? [#-what-types-of-content-can-i-import-with-spline]

<Callout>
  You can import content to your scene by dragging & dropping the file into the Viewport or with the Open/Import shortcut \[⌘ O].
</Callout>

Here is a list of the file formats you can import into Spline. Additional export types will come in the future.

* PNG
* JPG

## 🍭 Can Spline be integrated with other tools? [#-can-spline-be-integrated-with-other-tools]

Yes, if you export your scene for the Web as a **Public URL** ([Exporting as Public URLs](https://docs.spline.design/exporting-your-scene/web/exporting-as-public-ur-ls.md)), you can use the links or embed codes to embed it on platforms like Notion, Framer, Webflow, etc.

It’s also possible to integrate with the **Spline Viewer** ([Exporting as Spline Viewer](https://docs.spline.design/exporting-your-scene/web/exporting-as-spline-viewer.md)) code snippet, use **Code Exports** ([Exporting as Code](https://docs.spline.design/exporting-your-scene/web/exporting-as-code.md)) or the **Native Webflow Support** ([Integrating with Webflow](https://docs.spline.design/integrations/integrating-with-webflow.md)).

You can export [Native 3D Embeds for iOS](https://docs.spline.design/exporting-your-scene/apple-platform/native-3d-embeds-for-i-os.md) too which supports all Apple platforms iOS, iPadOS, macOS, and visionOS.

You can export [Native 3D Embeds for Android](https://docs.spline.design/exporting-your-scene/android/native-3d-embeds-for-android.md) which supports all Android devices including Phones, Tablets, Smart TV, and more.

## 💻 What are the technical requirements to run Spline? [#-what-are-the-technical-requirements-to-run-spline]

We recommend using the latest version of your OS to run Spline. 3D is a relatively new technology for browsers, and it requires more CPU/GPU processing than traditional 2D design tools.

If you are using a Macbook Pro with a discreet GPU card, a common suggestion is to enable high-performance settings by defaults.
