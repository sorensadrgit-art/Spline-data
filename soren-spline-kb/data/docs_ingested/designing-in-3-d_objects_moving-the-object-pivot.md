# Moving the Object Pivot (/designing-in-3-d/objects/moving-the-object-pivot)



Spline lets you change the pivot position of objects, groups, and components.

<Video src="https://docs.spline.design/media/pivot.mp4" />

Here’s how to do it:

1. Select the object, group, or component.
2. Press and hold ⌘ Cmd (macOS) or Ctrl (Windows).
3. While holding the key, drag the arrows on the gizmo to reposition the pivot.
4. A floating panel appears, allowing you to fine-tune the pivot’s transform values.

Note: Keep the key pressed while dragging gizmo via mouse. If you release it, the object itself will move instead of the pivot.

You can use this pivot workflow to create precise rotation animations. The tutorial below demonstrates common rotation setups.
