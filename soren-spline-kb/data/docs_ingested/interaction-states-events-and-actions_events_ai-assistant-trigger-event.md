# AI Assistant Trigger Event (/interaction-states-events-and-actions/events/ai-assistant-trigger-event)



The AI Assistant Trigger event is used in conjunction with the [AI Voice Assistant API](https://docs.spline.design/interaction-states-events-and-actions/variables-and-data/ai-voice-assistant-api.md) and allows you to trigger a set of actions when the user prompts the AI with something similar to the description of the trigger event.

***

## AI Assistant Trigger Event Properties [#ai-assistant-trigger-event-properties]

#### Trigger Description [#trigger-description]

In order for the AI to recognize which event to trigger, it will need a description of what the actions inside that event do.

For example, if we want the AI to move the blue cube in our scene, we can describe the trigger event as "move blue cube". When the AI is prompted to move the blue cube with natural language, it will understand that it needs to trigger the event with the description that matches the ask from the user.
