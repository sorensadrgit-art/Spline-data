# Open Link Action (/interaction-states-events-and-actions/actions/open-link-action)



An open link action lets you create links on your objects. It’s a great way to create experiences that need to be linked to other web pages.

## Creating a new Open Link Action [#creating-a-new-open-link-action]

1. Select the object that you want to add a link to.
2. On the Events panel, add one of the following events: Mouse Down / Up / Press or Key Down / Up / Press.
3. Open the Event and add an Open URL action.

## Customizing an Open Link Action [#customizing-an-open-link-action]

After your event is created, open the ‘Edit Event’ panel to customize your Open Link action.

* **URL** - Input the URL where you want to link to.
* **Target** - Decide how the link is going to be opened (Current Tab, New Tab, or New Window)
