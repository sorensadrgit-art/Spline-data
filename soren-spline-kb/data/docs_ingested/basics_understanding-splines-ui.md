# Understanding Spline's UI (/basics/understanding-splines-ui)

> A tour of the Spline interface — the dashboard, the 3D editor, Hana, and where each panel lives.



Below you can see an overview of Spline's UI.

## Dashboard [#dashboard]

<Image src="https://cdn.spline.design/_assets/docs/understanding-splines-ui-files-view-v2.png" alt="The Spline dashboard, with the tab bar, sidebar menu, Projects list and file grid numbered" />

1. The **Tab bar** keeps several files open at once. The home button on the left
   takes you back to your files, and the "+" opens a new tab. Tabs are a
   [desktop app](https://docs.spline.design/basics/download-spline-for-desktop.md) feature — in the browser
   each file gets its own window or tab.
2. The **Sidebar menu** moves between **Home**, **My files**, **Templates**,
   **Community** and **Academy**. Above it, the workspace name switches
   workspaces, alongside search and your notifications.
3. **Projects** are shared folders for organizing a workspace's work. Press the
   "+" to create one.
4. The **File view** lists what's in the section you're in — a preview, a name
   and when it was last edited for each file. The controls around it switch
   between **My files** and **Shared with me*&#x2A;, add a folder, toggle grid or
   list, filter and sort, and start something new with **+ Create**.

## Editor [#editor]

<Image src="https://cdn.spline.design/_assets/docs/understanding-splines-ui-editor-v2.png" alt="The Spline 3D editor, with the sidebar tabs, outliner, stage tabs, tool dock, share and export controls, property panels and viewport numbered" />

1. The sidebar's three tabs. **Agent** is the AI assistant that builds and edits
   the scene for you, and the tab the editor opens on. **Objects** is the scene
   tree, and **Assets** holds the asset browser and your team libraries.

   [AI Agent](https://docs.spline.design/spline-ai/ai-agent.md)
2. The **Outliner** — every object in the scene, nested and searchable. The
   **Scenes** list above it switches between the scenes in the file.

   [Multi-Scenes](https://docs.spline.design/designing-in-3-d/scenes/multi-scenes.md)
3. The **Preview | Edit | Code** stage tabs. **Edit** is the scene you work in,
   **Preview** runs it the way a visitor sees it — this is Play — and **Code**
   holds the file's own HTML document. Preview adds its own restart and
   full-screen chips beside the tabs.

   [Play Mode](https://docs.spline.design/exporting-your-scene/play-mode.md),
   [Code Tab](https://docs.spline.design/interaction-states-events-and-actions/code-tab.md)
4. The **tool dock**, where you add and manipulate content: the "+" opens the
   full list of objects, and the arrow is **Transform**, for moving, scaling and
   rotating what you select.
5. Zoom, scene performance, and the **Share** and **Export** buttons — the
   controls for inspecting and shipping the scene rather than editing it.

   [Exporting as Public URLs](https://docs.spline.design/exporting-your-scene/web/exporting-as-public-ur-ls.md)
6. The **Property Panels**. With nothing selected these are the scene's own
   settings — background, lights, simulation, effects, fog, sky, ambient
   shadows, color — and selecting an object swaps them for that object's
   properties.

   [Environment & HDRi](https://docs.spline.design/lighting/environment-and-hdri.md)
7. The **viewport** — the scene itself, where you select objects and move them
   around. What it shows follows the stage tabs above: the editable scene on
   **Edit**, the running one on **Preview**. Orbit, zoom and pan it with the
   mouse or trackpad.

   [Controlling the camera](https://docs.spline.design/basics/creating-your-first-scene.md#controlling-the-camera),
   [Keyboard shortcuts](https://docs.spline.design/basics/keyboard-shortcuts.md)

## Hana [#hana]

[Hana](https://docs.spline.design/hana-a-canvas-for-interactivity/basics/what-is-hana.md), the 2D editor, sits
in the same shell with panels suited to 2D work.

<Image src="https://cdn.spline.design/_assets/docs/understanding-splines-ui-hana.png" alt="The Hana 2D editor, with the sidebar tabs, pages and layers, toolbar, properties panel and canvas numbered" />

1. The sidebar's two tabs: **Agent**, Hana's AI assistant, and **Layers**, the
   document tree.

   [AI Agent in Hana](https://docs.spline.design/hana-a-canvas-for-interactivity/ai-in-hana.md)
2. **Pages** divide a file into separate canvases — think of them as the
   documents inside one file. Below them, the layer tree lists every frame and
   shape on the current page.

   [Pages in Hana](https://docs.spline.design/hana-a-canvas-for-interactivity/basics/pages-in-hana.md)
3. The **toolbar**, running down the left of the canvas: selection, frames,
   shapes, 3D shapes, text, comments and the vector tools, with **Play** at the
   bottom to run the design the way a visitor sees it.

   [Designing in Hana](https://docs.spline.design/hana-a-canvas-for-interactivity/basics/designing-in-hana.md),
   [3D Shapes in Hana](https://docs.spline.design/hana-a-canvas-for-interactivity/interactivity/3d-shapes-in-hana.md)
4. The **properties panel**. **Transform** and **Shape** cover position and size,
   **Layout** turns a frame into an auto layout, **States** and **Events** are
   where interactivity is authored, **Fill**, **Stroke** and **Effects** handle
   the look, and **Export** ships the frame. Zoom, **Share** and **Export** sit
   above it.

   [Auto Layout & Constraints](https://docs.spline.design/hana-a-canvas-for-interactivity/basics/auto-layout-and-constraints.md),
   [Interactivity in Hana](https://docs.spline.design/hana-a-canvas-for-interactivity/interactivity/interactivity-in-hana.md),
   [Effects in Hana](https://docs.spline.design/hana-a-canvas-for-interactivity/interactivity/effects-in-hana.md)
5. The **canvas**, holding as many **frames** as you like side by side. A frame
   is a screen or an artboard, and it's also the unit you publish — each one
   exports on its own.

   [Exporting in Hana](https://docs.spline.design/hana-a-canvas-for-interactivity/assets-and-export/exporting-in-hana.md)
